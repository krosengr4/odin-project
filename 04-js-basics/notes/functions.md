# FUNCTIONS

- Functions are the main building block of a program.
- They allow code to be called many times without repetition.

### Function Declaration
- First the "function" keyword.
- Next the name of the function.
- Next the comma-separated list of parameters within parenthesis.
- Lastly the function body in curly braces.
    - Ex:
        function showMessage() {

    }

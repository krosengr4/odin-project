# Clean Code

## Naming Functions and Variables
- A good name is descriptive.
- Good vocabulary is consistent.
- Variables should be a noun and functions should be a verb.
    - Ex:
    - Variable: numberOfThings, userName, selected
    - Function: getCount(), setTimeout()

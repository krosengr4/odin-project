# Problem Solving

- Problem solving is at the core of being a developer. It is the most important skill that a dev needs to have.
- Programming languages and other tools are secondary to problem solving.

## Techniques to Build Problem Solving Skill

### Understanding the Problem
- To better gain clarity and understanding of the problem to be solved:
    - Write it down on paper or type it out. Put it into your own words.
    - Draw diagrams or other visual helpers.
    - You have a solid understanding when you can explain the problem to someone else so they understand.

### Plan
- Once the issue is understood, *DO NOT* jump into coding.
- First, plan out your process to solve it.
- Some questions to ask yourself:
    - Does the program have a user interface? 
        - What will it look like? Make a mock up sketch.
        - What functionality will the interface have?
    - What inputs will your program have?
        - Will the user enter data or will you get it from somewhere else?
    - What is the desired output?
        - Given the inputs what are the steps necessary to return the desired output?
    - Where will you write out an algorithm to solve the problem?

### Pseudocode
- Write out the logic of the program in a natural language.
- Ex: 
    - When the user inputs a number
    - Initialize a counter variable and set its value to zero
    - While counter is smaller than user inputted number increment the counter by one
    - Print the value of the counter variable

### Divide and Conquer
- Each step in the pseudocode written above are sub problems.
- Pick the smallest or simplest one and start there.
- You may not know all the steps needed up front. Solving one sub problem at a time will reveal
    next sub problems to work on and clears up any confusions.
- Decomposition is the main way to deal with complexity. This makes problems easier and more
approachable to solve and understand.

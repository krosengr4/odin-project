# OPERATORS AND VARIABLES

### How to run JavaScript code
- For now, default to running javascript code in the browser, using console.log()
- This will require an HTML file.
    - Be sure to add the <script> tag.
    - Ex: "<script src="javascript.js"></script>"

### Variables
- Define variables with the let or const keyword.
    - Ex: let firstName = "John";
- The let keyword allows you to reassign the variable to another value.
- When using the const keyword, you cannot reassign that variable to another value. (this will throw an error)

- var is another keyword to define a variable that is similar to let.
- var is hardly used anymore because it is a worse version of let.

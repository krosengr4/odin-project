----- OBJECTS AS MACHINES -----

- Objects can be used to represent almost anything you can think of.
- Objects aren't just for representing physical data, but also conceptual logic as well.

- Examples of different kinds of object representations:
    - An object that manages other objects, like an "inventory" containing item objects in an array
    and methods that can be used to interact with that array of items.
    - An object that can listen for events to happen and respond appropriately (ex: .addEventListener).
    - An object that manages all things related to the DOM(document object model) that sets event
    listeners that call other objects methods, and displaying data from other objects.
